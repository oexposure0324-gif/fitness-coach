# 日常教練｜個人飲食與訓練

這是一個手機優先的繁體中文網頁工具，可記錄每日餐食、飲水、訓練組數、身體狀態、體重與腰圍。資料儲存在使用它的瀏覽器；沒有帳號或雲端同步。

## 在手機上使用

1. 將整個 `fitness-coach` 資料夾放在一台可持續開機的 Windows 電腦上。
2. 在該資料夾執行 `start-app.ps1`。如果 Windows 防火牆詢問，允許「私人網路」連線。
3. 確認手機和電腦連著同一個 Wi-Fi，在手機瀏覽器輸入腳本顯示的 `http://...:8765/` 網址。
4. 這個網頁在手機上可以直接操作。透過區網網址時請保持電腦和腳本執行；若要安裝成完整的離線主畫面 App，需先把整個資料夾部署到 HTTPS 靜態網站，再於手機瀏覽器選「加入主畫面」。

網頁資料分別存在每一台裝置的瀏覽器中，不會自動互通。跨裝置搬移請先在「個人設定」匯出備份，再到另一台裝置匯入。

## 功能

- 每日熱量、蛋白質、碳水、脂肪、纖維和飲水進度。
- 早餐範本、食物份量紀錄、手動營養輸入與四餐小計。
- 自建餐廳菜單，依當日剩餘熱量、蛋白質和脂肪排序。
- 依星期顯示訓練課表，記錄各動作重量、次數、RPE 和有氧完成情況。
- 參考前次表現提供「先加次數，再小幅加重」提示。
- 體重圖表、腰圍記錄，以及至少兩週資料後的保守調整建議。
- JSON 匯出與匯入。

## 資料與教練建議

內建常見食物的數值是參考估算，均標示 `ESTIMATE`；只有你確認來自包裝或店家標示時才選 `FACT`。資料會隨品牌、份量和烹調方式改變。餐廳資料需要自行新增，系統不會假裝知道未提供的菜單或營養資訊。

這個版本用明確的程式規則計算目標、餐點小計、訓練進度和體重趨勢；尚未串接生成式 AI、官方食品資料庫或即時店家菜單。設定裡的代謝公式只提供起始估算，不會自動大幅削減熱量。

## 電腦本機預覽

也可以直接用瀏覽器開啟 `index.html`。要測試 PWA 離線快取，請透過 HTTPS 網站或本機 `localhost` 開啟；一般手機主畫面 App 安裝也需要 HTTPS。
